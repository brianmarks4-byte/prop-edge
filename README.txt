PROP EDGE — Safari NFL Prop Analyzer

What this first version does:
- Enter player prop, side, line, American odds, model projection and model hit probability.
- Calculates sportsbook break-even probability, probability edge, expected value and fair odds.
- Generates a 0–100 leg rating and grade.
- Add multiple legs to a parlay.
- Calculates estimated parlay hit probability and fair decimal payout.
- Flags the weakest leg.
- Lets you apply a basic correlation-risk adjustment.
- Stores your current parlay on the phone/browser.

IMPORTANT:
This is the front-end/value calculator. It does NOT yet automatically generate NFL projections.
The next stage is a backend/API that pulls stats, injuries, matchups and current sportsbook lines.

How to use on iPhone:
1. Upload these files to any HTTPS static web host (GitHub Pages, Netlify, Cloudflare Pages, etc.).
2. Open the hosted URL in Safari.
3. Tap Share > Add to Home Screen.
4. It will launch like a standalone app.
